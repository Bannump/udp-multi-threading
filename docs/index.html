UDP Multi-Threading

Secure multi-threaded UDP packet processor with IPC monitoring — high-performance telecom-style component.

Overview

This project simulates a production-style network packet processor: a multi-threaded UDP server that receives encrypted custom packets, processes them with a thread pool, and reports statistics to a separate process via shared memory (IPC).

Components: C++ server (UDP + worker threads), monitor (shared-memory stats), Python client (encrypted packet generator), and an optional Streamlit dashboard.
